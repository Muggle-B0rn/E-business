# 🛠️ Some Tools 4 U

A curated collection of light web applications and interactive utility tools built with **HTML5, CSS3, and JavaScript**.

---

## 🚀 Included Projects

| Tool / Project | Key Files | Description |
| :--- | :--- | :--- |
| **Password Generator** | `index.html`, `Style.css`, `main.js` | A customized tool to generate strong, random passwords. |
| **XO Game** | `index.html`, `XO.css`, `XO.js` + (Media files) | Interactive Tic-Tac-Toe game featuring background video and sound effects. |
| **Sign-up / Log-in** | `index.html`, `log_in.html`, `log_in_sign_up.css` | Clean and responsive user authentication UI templates. |
| **Discount Calculator** | `index.html` | A simple calculator to compute final prices after applied discounts. |
